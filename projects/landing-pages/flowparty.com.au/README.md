# Flow Party Sydney — Website

The website for FLOW, Sydney's biggest Brazilian queer party — a single-page site introducing the brand, its mission, and its event history.

**Live site:** [flowparty.com.au](https://flowparty.com.au)
**Dev Link:** [brunovidasi.com/sydney](https://brunovidasi.com/sydney/)

## Sections

- **Masthead** — logo and tagline ("Biggest Brazilian Queer Party in Sydney")
- **Who We Are** — mission, vision, and values, plus a visual breakdown of the LGBTQIAPN+ community FLOW serves
- **Timeline** — a visual history of past editions (2021–2023), each with date, theme, and attendance
- **Team** — the people behind FLOW
- **Contact** — ways to get in touch
- **Sponsors** — partner/sponsor logos

## Built with

- HTML5 / Bootstrap 5
- Custom CSS (`css/styles.css`)
- jQuery + Bootstrap bundle JS
- Font Awesome icons
- Google Fonts (Montserrat, Roboto Slab)

## Structure

```
index.html
css/
  styles.css
js/
  scripts.js
assets/
  img/          → logos, banners, event flyers, icons
  favicon.ico
```

## Notes

Static single-page site — no build step required. Open `index.html` directly or serve the folder with any static host.
