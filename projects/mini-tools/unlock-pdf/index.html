How this works: with "Keep the original PDF as-is" on, your password is used to derive the file's real encryption key, every stream and string in the PDF is decrypted in place, and the password is removed — the result is the exact same PDF, just unlocked. If that isn't possible for a given file, it automatically falls back to re-rendering each page as a high-resolution image and reassembling those into a new, unencrypted PDF — that always works, but text won't be selectable or searchable in the result.
