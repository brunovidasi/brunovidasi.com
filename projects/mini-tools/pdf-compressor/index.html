How this works: the photos and scanned pages embedded in a PDF are almost always what make it large. This finds every JPEG image inside, decodes it, redraws it at a lower quality (and, past a size threshold, a lower resolution), and swaps it back in — only keeping the result where it's actually smaller. Text, fonts, and vector graphics are never touched, so the file stays crisp and searchable.
